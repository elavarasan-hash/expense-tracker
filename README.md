# Personal Expense Tracker with Visualization

A command-line Python application to record, categorize, and analyze personal expenses. Data is stored persistently in a local SQLite database, with spending summaries and visual reports generated using Pandas, Matplotlib, and Seaborn.

## Features
- Add expenses with date, category, amount, and an optional note
- Persistent storage using SQLite (no data lost between runs)
- Category-wise and month-wise spending summaries
- Visual reports: bar chart (spending by category) and line chart (monthly trend)
- Charts automatically saved as `expense_report.png`

## Tech Stack
- **Python** — core application logic
- **SQLite** — persistent local database
- **Pandas** — data aggregation and analysis
- **Matplotlib & Seaborn** — data visualization
